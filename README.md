# LeStudy - LeBron-Inspired Study Platform

LeStudy is a web-based study platform that combines productivity tools with LeBron James-themed elements to create an engaging and motivational learning experience.

## Features

### King's Court
A Pomodoro timer with LeBron reactions marking breaks. Focus like LeBron in the playoffs and track your study streaks.

### LeFlashcards
A spaced repetition flashcard system with LeBron-themed progression levels:
- Rookie
- Veteran
- All-Star
- GOAT

### The Playbook
Homework organization system with basketball-inspired priority levels:
- Regular Season (Low priority)
- Playoffs (Medium priority)
- Finals (High priority)

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Storage for data persistence

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Start studying like a champion!

## GitHub Pages

This project is set up to be deployed to GitHub Pages automatically. When you push changes to the `main` branch, the site will be automatically deployed to GitHub Pages.

To enable GitHub Pages for this repository:
1. Go to your repository on GitHub
2. Navigate to Settings > Pages
3. Under "Source", select "GitHub Actions" from the dropdown menu
4. Your site will be available at `https://[your-username].github.io/lockinwithbron/`
